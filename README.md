## 🔐 Security & Environment Variables

### Files NOT to Commit to Git

The following sensitive files are in `.gitignore` and must NEVER be committed:

1. **Backend Environment:**
   - `.env` - Contains database credentials, API keys, secrets
   - `serviceAccountKey.json` - Firebase service account private key

2. **Why?** These files contain:
   - Database passwords
   - API keys (Firebase, HuggingFace)
   - Secret keys for JWT signing
   - Private credentials

### Setting Up Environment Variables

#### Backend Setup

1. **Copy the template:**
   ```bash
   cp backend/.env.example backend/.env
   ```

2. **Update `backend/.env` with your values:**
   ```bash
   # Database
   MYSQL_USER=your_db_user
   MYSQL_PASSWORD=your_db_password
   MYSQL_SERVER=your_db_host
   
   # Security
   SECRET_KEY=generate_a_strong_key  # python -c "import secrets; print(secrets.token_urlsafe(32))"
   
   # Firebase
   FIREBASE_PROJECT_ID=your-firebase-project-id
   FIREBASE_API_KEY=your-firebase-api-key
   ```

3. **Optional: Add Firebase Service Account Key**
   - Download from Firebase Console → Settings → Service Accounts
   - Save as `backend/serviceAccountKey.json`
   - Set `FIREBASE_CREDENTIALS_PATH=./serviceAccountKey.json` in `.env`

#### Mobile Setup

1. **Backend URL:**
   - Update `lib/config/constants.dart`:
   ```dart
   static const String BACKEND_URL = 'your-backend-url';
   ```

2. **Firebase Configuration:**
   - Already configured via Firebase Console
   - See `lib/firebase_options.dart` (generated by FlutterFire CLI)

## 🚀 Quick Start

### Backend (FastAPI)

```bash
# Navigate to backend
cd backend

# Create virtual environment
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Setup environment variables
cp .env.example .env
# Edit .env with your values

# Run migrations
alembic upgrade head

# Start server
uvicorn app.main:app --reload
```

### Mobile (Flutter)

```bash
# Navigate to mobile app
cd mobile/aicointrack

# Get dependencies
flutter pub get

# Update backend URL in lib/config/constants.dart if needed

# Run on device/emulator
flutter run
```

## 🛠 Troubleshooting

### "Unknown column 'firebase_uid'" Error
- Run migrations: `alembic upgrade head`

### Firebase Token Verification Fails
- Check `FIREBASE_PROJECT_ID` in `.env`
- Ensure token is from the correct Firebase project

### Backend Cannot Connect
- Update `BACKEND_URL` in `lib/config/constants.dart`
- Check if backend is running and accessible

### Database Connection Error
- Verify MySQL is running
- Check `MYSQL_*` variables in `.env`
- Ensure database user has correct permissions

## 📝 Best Practices

✅ **DO:**
- Use `.env` for all configuration
- Keep `.env` and `serviceAccountKey.json` out of git
- Use environment-specific variables
- Rotate API keys regularly
- Use strong SECRET_KEY values

❌ **DON'T:**
- Hardcode credentials in source code
- Commit `.env` files to git
- Share API keys in messages/emails
- Use same keys for dev and production
- Log sensitive values

## 🚢 Production Deployment

Before deploying to production:

1. ✅ Update all `.env` variables with production values
2. ✅ Generate new `SECRET_KEY`
3. ✅ Set up production database with strong credentials
4. ✅ Configure production Firebase project
5. ✅ Update backend URL in mobile app
6. ✅ Enable HTTPS everywhere
7. ✅ Restrict CORS origins in `app/main.py`
8. ✅ Use environment-specific configuration
